# Awesome Claude Skills Gallery [![Awesome](https://awesome.re/badge.svg)](https://awesome.re)

> See what agent skills actually produce before you install them.

Every entry links to a real, public skill. Screenshots are either generated by this repo by running the skill's own code, or taken from the skill's own repo with credit. Star counts are refreshed manually for now (last update: 2026-10-14); a daily GitHub Action is ready but not enabled yet.

Browse the visual version at [omrigotlieb.github.io/awesome-claude-skills-gallery](https://omrigotlieb.github.io/awesome-claude-skills-gallery/).
